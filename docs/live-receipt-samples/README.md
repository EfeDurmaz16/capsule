# Golden Live Receipt Samples

These samples show the sanitized receipt shape expected from live provider tests. They are placeholders, not captured provider output.

- Resource ids, request ids, URLs, regions, hashes, and timestamps are deterministic examples.
- No provider account ids, credentials, connection strings, raw logs, or customer data are stored here.
- The `providerApiVersion`, `providerRegion`, `runtimeVersion`, and `adapterVersion` fields mirror the metadata each adapter can observe today.

Use `golden-live-receipts.json` when documenting provider evidence shape or building future receipt verification tools.
