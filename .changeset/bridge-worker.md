New package: a Capsule provider worker for the Fabric bridge protocol v1. It reads and writes u32 little-endian length-prefixed JSON frames (1 MiB from Fabric and for the handshake, 16 MiB for other worker frames, caps checked before a body is buffered), negotiates the protocol version, capability profile and limits in a hello, and then runs one governed sandbox action per request. Every refusal (schema, action outside the profile, locator scope, owner, policy, secrets, fresh approval, idempotency conflict) is answered with effect none before any provider call. Accepted work goes through the Capsule facade, so policy and the per-operation grant are checked again before the adapter runs. Terminal-only actions answer only after a terminal state was observed and otherwise answer pending with the scoped locator; an action whose effect cannot be known answers unknown with the best known locator. The worker keeps no durable state, never retries an effect, and never treats losing its connection as a cancel. The deterministic in-memory fixture provider records every effect for tests.
